# Security

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report privately via:

- GitHub **Security Advisories** for this repository (preferred), or
- An email to the maintainers if listed on the repo homepage.

Include steps to reproduce, affected versions, and impact.

## Scope

This project is a static kit installer (files + small Node CLI). Typical risks include supply-chain or social engineering around installation instructions — still report if you find something actionable.

## Supported versions

Security fixes are applied to the latest release on `main` unless otherwise communicated.
