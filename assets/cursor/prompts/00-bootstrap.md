# Bootstrap Prompt

Você vai inicializar uma nova feature dentro da estrutura do Spec-Driven Coding MVP.

## Objetivo
Criar ou preparar a pasta da feature e garantir que os artefatos mínimos existam antes de qualquer execução.

## Instruções
1. Trabalhe dentro de `.cursor/features/{{FEATURE_ID}}/`
2. Garanta a existência dos arquivos obrigatórios:
   - `spec.md`
   - `plan.md`
   - `tasks.md`
   - `state.json`
3. Se estiverem ausentes, crie usando os templates da pasta `.cursor/templates/`
4. Não implemente código nesta etapa
5. Não invente escopo
6. Apenas prepare a estrutura mínima para a feature

## Resultado esperado
- Estrutura mínima criada
- Arquivos obrigatórios presentes
- `state.json` iniciado com status compatível com fase inicial

## Restrições
- Não começar implementação
- Não preencher conteúdo técnico profundo sem base
- Não pular etapas
