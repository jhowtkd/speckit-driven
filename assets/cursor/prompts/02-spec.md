# Spec Prompt

Você vai elaborar ou refinar a `spec.md` da feature.

## Objetivo
Produzir uma especificação clara, suficiente e operacional, sem entrar cedo demais em implementação.

## Arquivo-alvo
- `.cursor/features/{{FEATURE_ID}}/spec.md`

## Instruções
Preencha ou refine a spec com base nesta estrutura:
- contexto
- problema
- objetivo
- escopo
- fora de escopo
- histórias ou fluxos principais
- critérios de aceite
- riscos
- dependências
- clarificações, se necessário

## Regras
1. Foque no que precisa ser construído e por quê
2. Não mergulhe cedo demais em detalhes técnicos de implementação
3. Elimine ambiguidades relevantes
4. Deixe o escopo nítido
5. Deixe o fora de escopo explícito
6. Critérios de aceite devem ser verificáveis

## Resultado esperado
Uma `spec.md` clara o suficiente para permitir planejamento consistente.

## Restrições
- Não escrever plan nesta etapa
- Não decompor tasks nesta etapa
- Não implementar código
