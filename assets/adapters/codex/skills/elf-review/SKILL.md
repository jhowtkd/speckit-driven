# ELF Review

Use this skill when you need to review a target through the ELF runtime.

## Rules

- Use `elf review <target>` for paths or run ids.
- Use `elf mcp serve` if you need Codex to inspect runtime state.
- Keep the review tied to the runtime, not to Codex-only prompts.
